# 示例说明

本目录提供了一个用于体验 PolymCrystIndex 工作流的示例数据集。

## 数据说明

- 数据来源：上海光源 SSRF 16B 线站
- 样品：HDPE 纤维样品
- 标样：Y2O3，使用 `pyFAI-calib2` 校准后得到 `Y2O3.poni`
- 图像经过空气散射背景校正

## 使用提示

- 可使用本目录中的示例文件练习导入、峰提取、积分和指标化流程。
- 进行指标化时，建议先将体积参数调小，推荐值约为 `50`。
- `c` 长度建议先在 `2-4` 范围内尝试。
